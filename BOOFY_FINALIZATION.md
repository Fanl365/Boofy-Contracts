## Deployment boundary
Rebranding does not create or verify blockchain deployments. Upstream addresses, transaction hashes, token symbols, pool IDs, fee recipients, treasury, governance, timelock, and multisig values must be replaced only with verified Boofy production values. Legally required upstream attribution is retained.
